Un flujo docente típico:

1. Preparar o editar una nota de clase.
2. Marcar su estado (`draft`, `private`, `published` o `public`).
3. Si va a usarse como presentación, agregar `reveal: true` o `theme: zztt`.
4. Abrir el icono de monitor para revisar Reveal.
5. Entrar a la sala performativa para compartir slides, audio, video o pods.

## Frontmatter mínimo para presentar

```yaml
---
title: Clase 04 — Ritmo y patrón
type: lesson
status: published
reveal: true
theme: zztt
---
```

## Ayuda mientras trabajás

Desde la ribbon de Musiki podés abrir ayuda contextual. Si Dockview está activo, la ayuda se abre como pod para consultar sin salir de la clase.
