**90 NOTAS** permite escribir, editar, comentar y exportar notas personales dentro del curso.

## Vista render

El botón de vista render muestra el Markdown como lo verá la plataforma. Algunos bloques interactivos, como Strudel, se renderizan con botón de reproducción y consola.

```js
n("0 1 2 3 4 5 6")
  .scale("C:major")
  .s("piano")
```

## Exportar

Desde el menú de descarga se puede exportar como:

- Markdown
- LaTeX
- plantillas LaTeX del seminario
- PDF

Las plantillas LaTeX viven como contenido de soporte y están marcadas internamente como `latex-template`.
