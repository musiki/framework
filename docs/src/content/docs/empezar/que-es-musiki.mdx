Musiki es un entorno de cursada y creación musical. No es solamente un campus: reúne lectura, edición de notas, presentaciones Reveal, foro, recursos, sala en vivo y pods interactivos.

## Las zonas principales

- **Vista normal del curso:** donde se leen clases, notas y recursos.
- **90 NOTAS:** espacio de escritura personal y exportación.
- **Sala performativa:** entorno LiveKit para cámara, micrófono, presentación, chat, mixer e instrumentos.
- **Pods:** paneles de trabajo acoplables, por ejemplo Strudel, LilyCode o ayuda contextual.
- **Reveal:** modo presentación de una nota cuando tiene `reveal: true` o un `theme`.

## Cuándo usar esta documentación

Usá `doc.musiki.org.ar` para resolver preguntas mientras trabajás. Desde Musiki también podés abrir esta ayuda como panel lateral o pod, sin abandonar la página activa.
