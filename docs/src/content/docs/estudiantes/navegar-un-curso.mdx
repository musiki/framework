La vista normal del curso tiene tres áreas:

1. **Navegación izquierda:** clases, conceptos, recursos y 90 NOTAS.
2. **Contenido central:** la clase o nota abierta.
3. **Barra derecha:** foro, información de página y paneles contextuales según la vista.

## Abrir una clase

Elegí una entrada del índice del curso. Si estás en una vista con Dockview activo, algunas notas se abren como paneles para poder compararlas o editarlas sin perder contexto.

## Abrir una presentación

Cuando una nota está preparada para Reveal, aparece el icono de monitor. Ese botón abre el modo slides.

Una nota habilita presentación si tiene alguno de estos campos:

```yaml
reveal: true
```

```yaml
theme: zztt
```

También funcionan `slideTheme` y `revealTheme`.
