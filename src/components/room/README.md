# room components

- `core`: shells y compositores.
- `generators`: fuentes performativas como `fm-synth` y `gravity-ball`.
- `processors`: procesos sobre audio o video.
- `mixing`: mixer, strips y controles de enrutamiento.
- `panels`: sidebars, setup, chat, notes y otros paneles plegables del dominio room.
- `stage`: paneles principales de escena y layout.
- `overlays`: capas flotantes, guías y feedback contextual.
- `snippets`: patrones pequeños reutilizables sin sobreactuar componentización.
