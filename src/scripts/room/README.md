# room scripts

- `core`: entrypoints y contratos base.
- `generators`: runtime de fuentes performativas.
- `processors`: runtime de audio y video processing.
- `mixing`: mezcla, buses y master.
- `layout`: estado de composición, URL y cambios de vista.
- `participants`: metadata, roles, foco/presencia, roster, cards y mounts de audio/video/screen.
- `session`: mensajes, contratos y estado compartido de la sala.
- `snippets`: helpers chicos y portables cuando no conviene abrir un módulo grande.
