Layout del editor de notas

¿Cómo debería organizarse la pantalla?

A

Split: árbol izquierda + editor derecha

Panel fijo de árbol de notas a la izquierda, editor de markdown a la derecha. Similar al editor de Obsidian.

B

Mejorar /notas con modo edición

La página /notas existente gana un modo "editar" que abre el editor inline. El árbol ya existe en notas.astro.

C

Página dedicada /notas-editor

Nueva página solo para teachers. URL: /notas-editor?course=i1. Árbol + editor completo sin distracciones.
